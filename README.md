# سُوق (SOOQ) - منصة التجارة الاجتماعية 🛍️💬

> المنصة الأولى التي تجمع بين إدراج المنتجات والمحادثات المباشرة بين البائع والمشتري لإتمام الصفقات بدون وسطاء.

## 🌟 المميزات الرئيسية

- **📦 متجر متكامل** - أنشئ متجرك وأدرج منتجاتك بسهولة
- **💬 محادثة فورية** - تواصل مباشر بين البائع والمشتري
- **🔒 دفع آمن** - معاملات موثوقة وآمنة تماماً
- **🎨 تصميم عصري** - واجهة احترافية وسهلة الاستخدام
- **📱 استجابة كاملة** - يعمل بسلاسة على جميع الأجهزة
- **🌍 دعم عربي كامل** - واجهة عربية احترافية (RTL)

## 🚀 البدء السريع

### التثبيت
```bash
git clone https://github.com/elazzouz-dotcom/sooq-marketplace.git
cd sooq-marketplace
```

### التشغيل المحلي
```bash
npm start
# أو
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## 📋 الأقسام الرئيسية

### 1. الشريط العلوي (Header)
- شعار سُوق | SOOQ مع أيقونة متجر وفقاعة كلام
- قائمة تنقل: الرئيسية، كيف نعمل، الاستكشاف، المتاجر، الأسعار
- زر "افتح متجرك مجاناً"

### 2. القسم الرئيسي (Hero)
- عنوان مؤثر مع عنوان فرعي
- زرا دعوة للإجراء: "حمل التطبيق" و "استكشف السوق"
- نموذج تفاعلي لجهاز iPhone

### 3. كيف نعمل (How It Works)
- 3 بطاقات تفاعلية تشرح آلية العمل
- أيقونات ملونة وجذابة

### 4. معاينة السوق (Live Marketplace)
- شبكة منتجات بـ 4 نماذج
- كل بطاقة تحتوي على خيار الدردشة المباشرة

### 5. مميزات المحادثة (Chat Highlights)
- عرض مقسوم للمميزات والمحادثة الفعلية
- واجهة شات حية وديناميكية

### 6. خطط الأسعار (Pricing)
- خطتان: البداية (مجاني) والمحترفين (PRO)

### 7. التذييل (Footer)
- روابط التحميل
- نموذج الاشتراك بالنشرة البريدية
- الروابط القانونية والاجتماعية
